LatePay 💸 — interactive demo

Every number below is a real TabPFN prediction (open-source tabular foundation model), precomputed on from simulated invoice data. No backend needed — the page only looks up precomputed results.

⚠️ SIMULATED / PRECOMPUTED: TabPFN was trained on a locally generated synthetic invoice history (4,000 invoices, seeded RNG). These are illustrative risk estimates, not financial advice.
